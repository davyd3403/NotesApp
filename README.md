# NotesApp

My first Python project.

## Description

NotesApp is a simple command-line application that lets you save and manage notes.

## Features

- Add notes
- View all notes
- Save notes to a text file
- Load notes automatically

## Technologies

- Python 3

## How to run

1. Make sure Python 3 is installed.
2. Open a terminal in the project folder.
3. Run:

   ```bash
   python notes.py
   ```
